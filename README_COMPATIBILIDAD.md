# Compatibilidad del TV Box

Esta app replica la arquitectura que resultó estable en **Ruleta Termas** y **APPJIRAFA**.

- Orientación: landscape
- minSdk 21
- targetSdk 25
- compileSdk 35
- Java nativo, sin Kotlin ni AndroidX
- Una sola Activity
- WebView local `file:///android_asset/index.html`
- Sin permiso INTERNET
- Modo inmersivo y pantalla encendida
- Frontend adaptado a JavaScript ES5 / WebView Android 7 API 25
- Diseño 1920 × 1080 (16:9 horizontal)
